**The Copper Ladle** is a complete cooking game about saving a beloved family diner. The bank gives you 12 days: hit each day's coin goal, serve the rush, and the ladle stays in the family. Play a full campaign — take orders from six kinds of customers, run a kitchen of chopping boards, grills, fryers, pots and an oven, build 24 recipes ingredient by ingredient (chop, grill, fry, boil and bake each one the way the ticket asks, and pull it off the heat before it burns), then spend the night's earnings on upgrades and new gear before the next, harder day. Every dish is assembled on a plate from raw ingredients you process yourself, so the fastest route through the kitchen is a plan, not a click race. Original art, names and sounds; it plays offline in a desktop browser from its own static files, with mouse and keyboard.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

To hand the entry in (copies `game/` and `screenshots/` to the output directory and writes `dossier.json`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
